# Reviewed project-file journal recovery

Dashboard project writes retain their selection binding inside the original
native workspace journal. This is provenance data, never a serialized permission
or approval. The ordinary native Receipt API and absent-setting bytes remain
unchanged. Journal progress, emergency updates and host CLI rollback preserve
the optional binding. No second journal namespace grants project writes.

Only current independently writable selected project files can enter this view.
Current Session/root/project, editing/read-only/query policy, host workspace
writes, native apply exclusions and current source scope remain authoritative.
The journal must match the current exact selection, workspace and single-file
native plan. Its before/after source evidence remains immutable. Other native
or older unbound journals stay in the original host recovery workflow.

Inspection uses finite explicitly requested pages. It reports skipped/unavailable
entries and cursor coverage; an empty page is never presented as a complete view
of every workspace journal. Recorded before/proposed bytes are inert text and
bounded by the selected document limit. Inspection never mutates source.

The browser offers only conditional rollback, with explicit confirmation. Resume
is not synthesized from stale workspace plans. The reviewed raw journal revision
is checked again while holding the original WriterLock, before any source or
journal mutation. The original native recovery checks every planned file,
restores only matching after-bytes and preserves foreign edits. Stale review,
expired requests, unknown fields and authority changes refuse. Unconfirmed
outcomes retain journal/plan IDs and the browser draft for another inspection.

The binding is not walked as a source/CAS retention grant. Original native plan,
snapshot and journal relationships remain authoritative. There is no automatic
recovery, file removal, new execution trust, configuration reload, model call or
execution of analyzed project code. Implementation and real qualification are
separate from this contract.

The [scoped acceptance](../../docs/validation/integration-2026-10-24/dashboard-project-recovery/README.md)
records 788 native passes in thirteen whole groups, all-target lint, 368-root
format/typecheck/npm gates and real stdio/HTTP/browser rollback. Focused results
and initial failures remain separate; screenshots are explicitly qualified.
This does not certify other journals, global binding migration or full STATUS.
